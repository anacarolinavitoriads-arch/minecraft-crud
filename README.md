# minecraft CRUD

## descrição

sistema CRUD desenvolvido em Python para cadastro e gerenciamento de jogos de minecraft.

o sistema permite cadastrar, listar, atualizar e excluir jogos.

## funcionalidades

- cadastrar jogos
- listar jogos cadastrados
- atualizar informações dos jogos
- excluir jogos
- validar os dados informados
- salvar os dados em arquivo binário

## dados cadastrados

cada jogo possui:

- nome
- plataforma
- ano de lançamento

## tecnologias utilizadas

- python
- biblioteca Pickle
- arquivo binário
